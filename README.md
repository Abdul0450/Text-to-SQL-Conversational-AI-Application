Text-to-SQL Conversational AI Application

An AI-powered application that converts natural language questions into SQL queries using Google Gemini and retrieves results from a SQL database. The application enables users to interact with structured data through a simple conversational interface without requiring prior SQL knowledge.
🚀 Project Overview
The Text-to-SQL Conversational AI Application bridges the gap between natural language and relational databases. Users can ask questions in plain English, and the system generates the corresponding SQL query, executes it against the database, and displays the results.
✨ Key Features
- Natural Language to SQL: Converts user questions into SQL queries using Google Gemini.
- Automated Query Execution: Executes generated SQL queries against the connected database.
- Conversational Interface: Provides an interactive web interface built with Streamlit.
- Dynamic Data Retrieval: Fetches and displays database records based on user questions.
- Database Management: Supports database schema creation and record insertion for testing and querying.
- Prompt Engineering: Uses structured prompts to guide the LLM in generating relevant SQL queries.
